# PLP Python Week 3

This project contains two Python programs:

- `grade_reporter.py` - grades a list of scores, counts pass/fail, and calculates the average.
- `bug_hunt.py` - fixes the loop bug and prints the sum of 1 to 5.

## Run the programs

```bash
python grade_reporter.py
python bug_hunt.py
```

## Expected output

`grade_reporter.py` prints each score with its grade, the pass/fail count, and the average.

`bug_hunt.py` prints:

```text
Sum of 1 to 5 is: 15
```
